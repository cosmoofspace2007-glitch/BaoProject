24. TƯ DUY CODE ĐÚNG
KHÔNG:
•	code tất cả trong 1 file
•	controller xử lý toàn bộ logic
NÊN:
•	1 chức năng = 1 module
•	controller chỉ nhận request
•	service xử lý nghiệp vụ
•	repository xử lý database
Ví dụ:
•	auth.js
•	article.js
•	comment.js
•	writer.js
•	editor.js
•	admin.js
